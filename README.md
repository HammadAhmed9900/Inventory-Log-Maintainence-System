# Inventory Log Maintenance System

A simple **C++ console-based Inventory Log Maintenance System** developed using basic programming concepts such as **integer arrays, character arrays, loops, file handling, and conditional statements**.

## Features

* Add new item records
* View all items
* Search item by ItemID
* Update quantity or price
* Delete item records

## Concepts Used

* Integer Arrays
* Character Arrays
* Loops
* File Handling (CSV Files)
* Functions
* If-Else Statements

## How to Run

```bash
g++ main.cpp -o inventory
./inventory
```

## Purpose

This project was created to practice **file handling in C++**, especially working with CSV files, updating records, and maintaining data consistency using temporary files.
